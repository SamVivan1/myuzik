## 0. Ringkasan eksekutif — 8 temuan teratas

| ID | Sev | Satu baris |
|---|---|---|
| UI-01 | **P0** | Semua kontrol hanyalah tab-stop: **Enter/Space tidak pernah mengaktifkan apa pun**, karena `on_click` di gpui hanya dari mouse dan aplikasi tidak punya `on_a11y_action` maupun key binding. |
| UI-02 | **P0** | `toast` diisi di tiga tempat tapi **tidak pernah dirender** — kegagalan playback, autoplay, dan library hilang tanpa jejak. |
| UI-03 | P1 | Halaman Search hanya merender grup **Songs**; album/artist/playlist diambil tapi tidak pernah tampil, dan bila hanya album yang cocok layar menjadi **kosong tanpa pesan**. |
| UI-04 | P1 | Hasil pencarian **tidak bisa dijalankan dengan keyboard**; Tab sampai ke baris hasil, Enter tidak bereaksi, dan **Space men-toggle playback**. |
| UI-06 | P1 | Token `text_tertiary` `#7C756A` = **4.29:1** pada glass (gagal AA 4.5:1), dipakai sebagai teks nyata di 12 tempat termasuk caption 8–10 px. |
| UI-08 | P1 | Setelan **Reduce motion yang tersimpan di config tidak pernah diterapkan saat start**; `cx.set_reduce_motion` hanya dipanggil dari handler toggle. |
| UI-09 | P1 | Route Now Playing tanpa track menampilkan **halaman kosong**, header selalu berbunyi "SYNCED LYRICS" walau lirik instrumental/plain/error, dan footer mencetak `" — "`. |
| UI-10 | P1 | Centering lirik memakai **aritmetika `-(active * 40)` dengan `viewport_height` hardcoded 400** yang tak pernah diperbarui; `target_offset()` yang benar justru tidak dipakai render. |

Temuan paling berdampak untuk pengguna mouse juga: **UI-11** (tidak ada truncation sama sekali → judul panjang membungkus di dalam bar player 260 px dan membuat grid album bergerigi) dan **UI-12** (`os_accent` dipakai sebagai isi bar volume, melanggar aturan token sendiri di design.md:206).

## 4. Yang sudah baik

Hal-hal berikut saya periksa dan tidak perlu diperbaiki; jangan tersapu oleh refactor apa pun.

1. **Disiplin token material.** `src/theme.rs` memisahkan glass/clay/gold/ambient dengan 40 field (`theme.rs:11-52`) dan hampir seluruh render membaca token. Penyimpangan warna mentah terbatas pada daftar UI-27 yang bisa dihitung jari.
2. **Ring fokus tanpa layout shift.** `Shell::focus_border` (`shell.rs:532-544`) dengan `border_2()` yang selalu dipesan adalah solusi tepat untuk gpui rev ini yang belum punya outline API; dikunci `tests/a11y.rs:493-500`.
3. **Urutan fokus yang nyata dan dapat dibalik.** Empat grup `TAB_NAV/CONTENT/PLAYER/CHROME` (`shell.rs:499-502`) dengan `focus_for` (`:505-520`) memakai handle per nama sehingga identitas kontrol stabil antar-frame; diuji bolak-balik (`tests/a11y.rs:217-286`).
4. **Perlindungan input teks.** Guard `search_focus` di `shell.rs:2286` mencegah Space men-toggle playback saat mengetik, dan Tab ditangani **sebelum** guard (`:2277-2285`) sehingga tetap bisa keluar dari field — detail yang sering salah; diuji `tests/a11y.rs:290-329`.
5. **Struktur aksesibilitas container.** `Role::Grid` untuk grid album (`:3284`), `Role::List`/`Role::ListItem` untuk artist (`:3177`/`:3189`), playlist (`:3227`/`:3239`), track list (`:3537`/`:3556`), dan `aria_selected` pada nav (`:2593-2600`) — screen reader akan mengumumkan jumlah item. Ini melampaui banyak aplikasi sejenis.
6. **Reduce motion dihormati oleh mesin animasi.** Setelah cfg diterapkan (UI-08), semua animasi `with_animation` otomatis statis: `crates/gpui/src/elements/animation.rs:407-416` mengambil delta 0.0/1.0 dan menandai `done`. 7. **Anggaran layout bawah sadar-cadangan.** `.pb(112)`/`.pb(118)` vs bar 88+18 (`:2657`, `:2529`, `:1776`) — konten terakhir tidak pernah tertutup permanen oleh bar melayang.
8. **Lirik tidak pernah berupa kotak kosong.** Keenam `LyricsStatus` punya pesan (`lyrics_view.rs:63-107`); `Loading`, `Instrumental`, `NotFound`, `Error` semuanya berkalimat.
9. **Fallback cover tanpa layout shift.** `aspect_ratio(1.0)` (`:3918`, `:3972`) + inisial huruf Fraunces (`:3999-4007`) menjaga grid stabil saat art belum termuat.
10. **Setup tidak mem-prefill password** (`shell.rs:168`) — keputusan keamanan yang benar.
11. **Minimum window size konsisten** antara kebijakan window (`src/main.rs:19`) dan grip resize (`shell.rs:3611-3612`) — tidak ada jalan bagi user untuk mengecilkan UI sampai rusak.

## 6. Tidak diverifikasi

Daftar ini jujur tentang batas audit; jangan dibaca sebagai "aman".

1. **Tidak ada GUI yang dijalankan** (tanpa display). Semua klaim visual bersandar pada kode + empat screenshot headless. Perilaku hover, transisi 180 ms, dan animasi nyata tidak saya lihat.
2. **`cargo check --offline` dijalankan dan lulus** (`Finished dev profile in 0.38s`, cache). **`cargo build` penuh dan `cargo test` tidak dijalankan** — jadi saya tidak memverifikasi bahwa `tests/a11y.rs` benar-benar hijau saat ini, maupun klaim di `docs/accessibility.md` bahwa 7 test lulus. Saya membaca test itu dan menganggapnya sebagai *niat* pengunci, bukan bukti status.
3. **Screenshot headless tidak menggambar tekstur gambar** (`design-audit.md:94-95`), jadi semua cover album tampil sebagai gradient placeholder. Saya tidak dapat menilai kualitas crop/`ObjectFit::Cover`, ketajaman art, atau perilaku saat cover 512 px ditampilkan pada 288 px.
4. **Aktivasi keyboard (UI-01) perlu verifikasi runtime.** Bukti saya statis: gpui `on_click` hanya mendaftarkan listener mouse (`crates/gpui/src/elements/div.rs:615-620`), tidak ada `on_a11y_action` di `src/`, dan hanya tiga `on_key_down`. Konfirmasi akhir tetap harus berupa menekan Enter pada nav item di sesi hidup.
5. **Besar pergeseran centering lirik (UI-10) adalah estimasi aritmetika**, bukan pengukuran. Kasus yang memperburuk (baris membungkus) belum saya reproduksi.
6. **Edge tepi ambient blob (UI-14)** bisa sebagian merupakan artefak renderer headless; mekanisme `bg` solid terbukti dari kode, intensitas visual tidak.
7. **Kontras dihitung analitis** dari token `theme.rs`, bukan diukur dari piksel screenshot. Efek compositing nyata (gradient clay, ambient blob, `.opacity(0.7)`) saya hitung dengan asumsi over-compositing sederhana. Angka UI-06 (4.29:1) adalah batas atas — ambient blob yang lebih terang akan menurunkannya.
8. **Reader layar (Orca) tidak dijalankan.** Klaim "role/label ada" hanya source-level, sesuai batasan yang sudah didokumentasikan `docs/accessibility.md:101-110`.
9. **IME / input non-Latin tidak diuji.** Kedua field teks adalah `div` buatan tangan (`shell.rs:1602`, `:2809`) yang membaca `keystroke.key_char`; sangat mungkin tidak berfungsi untuk IME (Jepang/Arab/huruf beraksen) dan untuk dead keys. Ini tanda bahaya, bukan temuan terverifikasi.
10. **Perilaku pada server lambat/putus** tidak diuji (tidak ada server). `docs/design.md:466` soal offline tidak dapat diverifikasi.
11. **`src/overlay/mod.rs` (1284 baris) di luar lingkup file tugas ini** — dikerjakan task alur/state. Saya hanya menyentuhnya sebagai bukti pemakaian token (`overlay/mod.rs:725`, `:820`) dan tidak menilai layout overlay dari screenshot (`overlay*.png`) secara sistematis.
12. **Rasio kontras `gold_deep` 4.07:1** sengaja **tidak** dilaporkan sebagai kegagalan karena pemakaiannya hanya grafis (ambang 3:1). Bila kelak dipakai sebagai teks, ia akan gagal.
