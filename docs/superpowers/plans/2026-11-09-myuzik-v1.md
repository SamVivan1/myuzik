# Myuzik v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Myuzik v1 — a low-RAM, native Rust/GPUI Navidrome player for Linux with synced lyrics, a pinned desktop lyric overlay, MPRIS, and the Midnight Brass visual system.

**Architecture:** A single GPUI desktop process with a background HTTP library, a dedicated GStreamer player thread, a shared lyrics engine, and a second GPUI window for pinned lyrics. A small companion GNOME Shell extension pins the lyric window above other windows on GNOME 51 Wayland. Navidrome is accessed through the Subsonic API; lyrics come from Navidrome/OpenSubsonic and LRCLIB with a local cache. MPRIS exposes playback to the desktop.

**Tech Stack:** Rust 1.99 (edition 2024), GPUI (Zed, pinned after 2026-10-30), GStreamer 0.25 (`v1_24`), Navidrome Subsonic API + OpenSubsonic, LRCLIB, `ureq` 3, `mpris-server` 0.11, `keyring` 4.2, `ashpd` 0.14, `image` 0.25, `serde`, `toml`, `flume`, `tracing`.

**Spec:** `/home/samvivan/.opencode/plan/myuzik/design.md` (copy to `docs/design.md` in the repo at Task 1). The approved visual reference is `/home/samvivan/.opencode/plan/myuzik-mockups/visual-style-midnight-brass.html` (copy to `docs/mockups/midnight-brass.html`).

**Execution model requested by user:** `opencode-go/beam-free` (Beam Free) in Build mode. This plan is written to be self-contained for that model: every task names files, interfaces, exact tests, and manual verification.

## Global Constraints

- Rust 1.99, edition 2024. Run `cargo fmt` and `cargo clippy --all-targets -- -D warnings` before every commit.
- GPUI dependency: `gpui = { git = "https://github.com/zed-industries/zed", rev = "14b7b0ef3764d62a85070c8b5ccea105a2ad3235" }` or a later commit containing `ext-background-effect-v1` (merged 2026-10-30, PR #53746). Do not use crates.io `gpui 0.2.2` for the blur feature; it predates the protocol support.
- GStreamer baseline: 1.24 APIs, `gstreamer = { version = "0.25", features = ["v1_24"] }`. System runtime on the target is 1.28.7; build headers must be installed.
- App ID: `io.github.samvivan1.Myuzik`. Main window title: `Myuzik`. Overlay title must be exactly `Myuzik Lyrics`.
- GNOME extension UUID: `myuzik-pin@samvivan1.github.io`.
- Visual system: Midnight Brass only. No pixel font in the default theme. Gold = state; OS accent = focus/selection; glass = surfaces; clay = controls.
- Exact palette tokens are in the spec §6.1 and must live in `src/theme.rs`; components never hardcode raw colors.
- Typography: Fraunces (display) + Inter (UI/lyrics), bundled with OFL licenses.
- Credentials: Secret Service via `keyring`; never log passwords, salts, or tokens. Fallback to 0600 config only with explicit consent.
- No telemetry. LRCLIB requests contain only artist/title/album/duration.
- Memory budgets: idle ≤ 200 MB RSS, playing+overlay ≤ 250 MB RSS; startup ≤ 1.5 s to first usable frame on SSD.
- All network I/O off the UI thread. No blocking in render/update paths.
- Lists are virtualized/paginated; no full-library fetch. Covers request 512 px and use an LRU.
- Every icon-only control has an accessible label. Keyboard focus is always visible. Reduced motion is honored.
- Commit after each task; conventional commit messages (`feat:`, `fix:`, `test:`, `chore:`).
- UI copy is English. Code comments are English. User-facing docs may include Indonesian notes.

## Review Focus

These are the five input classes/failure modes most likely to bite a user. Each has a test in the owning task; do not ship without them.

1. **Bad server state:** unreachable server, wrong password, HTML/non-JSON response, timeout, TLS failure, unsupported Navidrome version. Expected: actionable inline/toast error, no panic, setup remains usable.
2. **Lyrics edge cases:** no lyrics, instrumental, plain-only lyrics, very long lines, CJK/Arabic/Devanagari text, 500+ lines, offset extremes. Expected: correct status, readable wrapping, active line fully visible in the overlay, no truncation of the active line.
3. **Playback races:** rapid next/prev, seek during buffering, EOS while paused, track change while lyrics fetch is in flight. Expected: one consistent current track, one scrobble, correct MPRIS position/status, stale lyric response discarded.
4. **Platform fallback:** GNOME 51 with/without extension, no blur support, X11/XWayland, 200% scaling, multi-monitor. Expected: app and overlay remain usable; glass falls back to a dark tint; no crash; extension hint shown.
5. **Scale and flakiness:** 20k-track library, slow LAN, repeated search queries, repeated cover loads. Expected: paginated/virtualized UI, cancellations, LRU eviction, no unbounded memory growth.
