GLASS = SURFACE

Jendela, sidebar, kartu, panel lirik. Blur native GNOME 51 hanya dipakai di permukaan besar, supaya hierarki tetap jelas.

CLAY = CONTROLS

Player bar, tombol play, toggle pin, search, offset. Semua yang bisa ditekan terasa empuk dan punya bayangan fisik.

GOLD = STATE

Hanya untuk baris lirik aktif, progress, tombol play, dan logo. Maksimal sekitar 10% permukaan; gold tidak pernah jadi warna latar.

Aa

TYPE = READABILITY

Fraunces untuk display, Inter untuk UI dan lirik. Tanpa font piksel; lirik tetap lapang dan kontras.

Aturan warna: gold hanya untuk state dan now playing; biru OS hanya untuk focus ring/seleksi. Permukaan besar tetap warm black glass dan ivory clay. Aturan tipografi: Fraunces untuk display, Inter untuk UI dan lirik; tanpa font piksel di default. Kalau pixel masih diinginkan, ia menjadi tema opsional — bukan identitas v1.
